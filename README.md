# Gleuderoff — редактор мира

Настольная программа (Windows) для лора D&D-мира Gleuderoff: интерактивная карта, государства, таймлайн и справочник.

## Установка
`release/Gleuderoff-Setup-0.1.0.exe` — обычный установщик. Создаёт ярлык на рабочем столе.

Данные мира хранятся в `Документы\Gleuderoff\worlds\gleuderoff\`:
- `world.json` — весь лор;
- `assets\` — флаги, портреты, карты городов;
- `backups\` — копия при каждом запуске (последние 40).

## Разработка
```
npm install
npm run dev        # запуск в режиме разработки
npm run dist       # собрать установщик в release/ (упаковщику NSIS нужно ~250 МБ во временной папке: если на C: мало места — TEMP=E:/tmp TMP=E:/tmp npm run dist)
```

Сборка стартового мира (resources/default-world) — по порядку:
1. `node --max-old-space-size=8192 scripts/import-psd.mjs` — страны и их подписи из `source-maps/political.psd`;
2. `node scripts/seed-lore.mjs` — лор из `scripts/lore/*.mjs` и `source-lore/*.md` (боги, расы, Монстарги, государства, география);
3. `node --max-old-space-size=8192 scripts/provinces.mjs` — тысячи провинций: местность, иерархия (континент → регион → область → провинция), культуры, имена;
4. `node --max-old-space-size=8192 scripts/smooth-provinces.mjs` — плавные границы провинций, закрытие щелей от линий PSD, соседи;
5. `node --max-old-space-size=8192 scripts/terrain.mjs` — маска рек и поселения провинций (деревни, города, порты, замки…);
6. `node scripts/history-provinces.mjs` — постепенная история владения: завоевания Тейбера, восстания, Лесная война, распад 975–980; великие дома за регионами; места битв;
6а. `node scripts/empire-detail.mjs` — описания поселений Империи, низшая знать округов, гнёзда домов, кастры легионов, Аурхафен;
6б. `node scripts/argus-detail.mjs` — Корона Аргус: столица Норерштадт, младшие дома округов, описания поселений;
6в. `node scripts/legislatures.mjs` — собрания по годам: Верховный совет, Сенат Короны, Народное собрание Республики с выборами по весу голоса и кабинетами, семь городских парламентов, Совет рабочих;
6г. `node scripts/republic-detail.mjs` — Республика: столица Тиррит, округа и губернаторы, описания поселений, «Освобождение 977» у каждого взятого города, особые места, казни Охоты и стачки на карте;
6д. `node scripts/south-detail.mjs` — южные республики (Тоскана, Вуфинская, Шеша, Кальтрания; лор — `scripts/lore/south*.mjs`, парламенты и комитеты собирает legislatures.mjs): доимперские государства юга, описания поселений, столицы;
6д'. `node scripts/church-detail.mjs` — Святая церковь (лор — `scripts/lore/church.mjs`, Совет святых архиепископов собирает legislatures.mjs): описания поселений архипелага и архиепархий;
6д''. `node scripts/styria-detail.mjs` — Графство Штирия (лор — `scripts/lore/styria.mjs`, Ночной совет — в `legislatures.mjs`): описания поселений, столица, тайные места, роты на перевалах.
6д'''. `node scripts/mangenium-detail.mjs` — Графство Мангениум (лор — `scripts/lore/mangenium.mjs`): города Манген, Ним, Нарни, Граднец на месте прежних городков, описания поселений, столица и памятные места, стража на заставах 978 г.;
6е. `node scripts/city-maps.mjs` — планы городов: генератор Watabou (план в `source-maps/cities/*.json`) → карта в стиле мира, контуры зданий для выбора, примечательные здания метками; SVG рисует Chromium (секунда на город). Новый город: добавить в `scripts/lore/cities.mjs` и запустить `node scripts/city-maps.mjs gen <slug>` — генератор Watabou откроется в скрытом окне Electron (`scripts/city-gen.cjs`), план и карта готовы за ~10 с. Города, городки, порты и кастры без ручного описания (а на юге — и все деревни) настраиваются сами по описанию провинции — `scripts/lore/cities-auto.mjs`. Город особой планировки (Хауссер) строит свой скрипт (`custom` в cities.mjs, `scripts/hausser-plan.mjs`); В каждый план пишется и `scene` (улицы, стены, вода, поля, масштаб, стиль государства): из неё `src/renderer/src/city3d.ts` прямо в приложении строит 3D-вид и прогулку (кнопки «3D» и «Прогулка» над планом). Улицы и маршруты жителей выводятся из плана (`city3dStreets.ts`), особые здания выбираются по названию с плана (`city3dMonuments.ts`), жители — `city3dLife.ts`, внешность народов и состав населения по регионам (черновик) — `city3dRaces.ts`.
6ж. `node scripts/army-routes.mjs` — походы армий по дорогам и местности: поиск пути по сетке карты (тракт дешевле всего, горы дороже, море непроходимо) → `waypoint.path`; за море — напрямую;
7. `node --max-old-space-size=8192 scripts/roads.mjs` — дороги между поселениями: мощёные тракты, грунтовки, горные тропы (`source-maps/roads.json`);
8. `node --max-old-space-size=14000 scripts/render-map.mjs` — новая подложка 32768×18688: рельеф со светотенью и тенями гор, кроны деревьев, пашни, дороги, скалы и снега, барханы, реки, мелководье (≈3 мин);
9. `node --max-old-space-size=12000 scripts/make-tiles.mjs` — плитки 1024 px, уровни z −4…2.

Версия для телефона: `npm run build:web` → папка `out-web` (плитки до z=1), публикуется закрытой страницей на claude.ai.

Портреты: `node scripts/portraits.mjs` (персонажи) и `node scripts/deputy-portraits.mjs` (члены собраний Республики) — stable-diffusion.cpp с DreamShaper 8 (`tools/sd`, не в git) через `scripts/sd.mjs`: модель один раз грузится в `sd-server` и держится в памяти, декодер TAESD. Персонажи — LCM-LoRA, 7 шагов, 448×560 (на 512×640 не хватает 4 ГБ видеопамяти и шаг в 5 раз медленнее) с увеличением — ~20 с; депутаты — Hyper-SD (2-step LoRA на силе 0,6, сэмплер TCD, 3 шага) — ~5,5 с. `SD_FAST=1` включает быстрый режим и для персонажей (~7 с, но без отрицательного запроса).

Подробный план карты — [MAP_PLAN.md](MAP_PLAN.md).

Подложка: Real-ESRGAN (`tools/realesrgan`, не в git) увеличивает `source-maps/base-4096.png` в 4 раза, затем `node scripts/make-tiles.mjs` режет плитки.

Если стартовый мир меняется — поднимите `version` в `seed-lore.mjs` и допишите шаг в `migrateWorld` (src/main/index.ts), чтобы обновить миры пользователей без потери их правок.
