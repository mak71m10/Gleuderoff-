## 3. Что уже есть в мире (возможности приложения)

- **Карта мира:** провинции, области, земли и континенты; режимы (политика, религии, рельеф); векторные реки, озёра с глубиной,
  горы с отмывкой; значки поселений как миниатюры их планов; подписи; ползунок даты, «время идёт».
  Серебряная Ива и Стена отчаяния — 3D-модели прямо на карте.
- **История:** у провинций есть владельцы по датам (`owners`), смена правителей (`history` у стран), походы армий по дорогам (`armies`),
  битвы и события (`places` с годом).
- **Карточка страны** (`StateCard.tsx`): шапка, гербы, фракции, «Власть и законы» с экраном механики, кнопки «План: город»,
  возврат «назад» с сохранением масштаба.
- **Кодекс** (`Codex.tsx`): династии, люди, организации, артефакты, книги гербов; родословные древа (`DynastyTree.tsx`, `families/*.mjs`);
  тайны в поле `secret` — видны в режиме мастера.
- **Портреты:** северноевропейские лица, рисуются локально (`scripts/portraits.mjs`, `tools/sd`).
- **Города:** планы у всех поселений проработанных стран (органический генератор `city-organic.mjs`, проверка `city-check.mjs`, П1–П10);
  3D-города (`city3d.ts`) со стилями стран, особыми постройками, горами за краем, светом дня, вечера и ночи.
- **Прогулка по 3D-городу:** жители ходят по улицам, говорят реплики по стране и власти (`city3dSpeech.ts`), лестницы на стены, подъём без полёта.
- **Платформы:** Windows (Electron), Android (Capacitor), веб-превью.

- **Старые страны** (Империя, Аргус, Штирия, Мангениум, южные республики) показаны общим залом — до новой планки не дотянуты.

- **Механики мира** (не власти) — только жители, реплики и прогулка. Идеи (события по дате, слухи, стража по закону страны)
  лежат в `handoff-mehaniki.md`.

## Скрипт пересчёта

```bash
node -e "
const w=require('./resources/default-world/world.json');
const ad=new Map(w.adminRegions.map(a=>[a.id,a]));
const cont=p=>{let a=ad.get(p.areaId);while(a&&a.level!=='continent')a=ad.get(a.parentId);return a?.name||'?'};
const org=new Set(w.entries.filter(e=>e.kind==='organization'&&/Государственный орган/.test(e.base?.props?.type||'')).flatMap(e=>e.base.tags||[]));
const st=new Map(w.states.map(s=>[s.id,s]));const c={};
for(const p of w.provinces){const o=p.owners?.at(-1)?.[1];if(!o)continue;const k=cont(p)+'|'+o;c[k]=(c[k]||0)+1}
const out={};for(const [k,n] of Object.entries(c)){const [ct,id]=k.split('|');const nm=st.get(id)?.base.name;(out[ct]=out[ct]||[]).push(nm+' '+n+(org.has(nm)?' ✔':''))}
for(const k in out)console.log(k+': '+out[k].join(', '))"
```
(`✔` — у страны есть государственный орган; старые залы тоже дают `✔`, поэтому смотри и на таблицу выше.)
