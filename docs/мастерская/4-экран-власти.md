# 4. Экран власти: как превратить механику в интерактивную картинку

Каждая страна показывает свою власть во вкладке «Власть и законы» карточки государства (и в «Кодексе»).
Экран — **одна метафора + ползунок/вкладки + карточки**. Образцы по возрастанию сложности:
`Ting.tsx` → `Stavka.tsx` → `Heights.tsx` → `Urn.tsx` → `Fleet.tsx` → `Lantern.tsx`.
Самые свежие и чистые — **`Fleet.tsx` и `Lantern.tsx`**: копируй их структуру.

---

## 1. Путь данных (5 точек, все обязательны)

1. **Лор:** `scripts/lore/<страна>.mjs` — функция `xxxData()` возвращает объект, орган власти:
   ```js
   org('xx-circle', 'Имя органа', { props: { type: 'Государственный орган', … }, lantern: lanternData(), body, secret })
   ```
2. **Пропуск поля в мир:** `scripts/seed-lore.mjs`, функция `E()` — строка
   `...(f.lantern ? { lantern: f.lantern } : {})`. **Без неё поле молча пропадёт.**
3. **Тип:** `src/renderer/src/types.ts`, рядом с `fleet?:`/`lantern?:` — однострочный тип поля.
4. **Подключение:**
   - `StateCard.tsx`: фильтр `organs` (добавить `|| e.base.xxx`) и вывод `{of.xxx && <XxxView data={of.xxx} onOpen={open} />}`;
   - `Codex.tsx`: вывод `{f.xxx && <XxxView data={f.xxx} onOpen={goto} />}`;
   - импорт `import { XxxView } from './Xxx'` в обоих.
5. **Стили:** `src/renderer/src/styles.css` — блок с префиксом (`.lan-*`, `.fleet-*`) в конце файла и
   правило в телефонном блоке `@media (max-width: 760px), (max-height: 520px) and (orientation: landscape)`
   (ищи строку `.fleet-face { width: 34px` — она внутри этого блока).

Проверка после: `node scripts/seed-lore.mjs` → весь конвейер (гайд, раздел 10) → `npx tsc --noEmit -p .`.

## 2. Скелет компонента

```tsx
import { useMemo, useState, type ReactNode } from 'react'
import { useStore } from '../store'
import { assetUrl } from './ui'
import { EMBLEMS } from './Heraldry'          // эмблемы в поле 100×100: EMBLEMS[key].draw(fg, bg)
import type { Entry } from '../types'

type Data = NonNullable<Entry['base']['xxx']>
const bold = (s: string): ReactNode[] => s.split(/\*\*(.+?)\*\*/g).map((t, i) => (i % 2 ? <b key={i}>{t}</b> : t))

export function XxxView({ data, onOpen }: { data: Data; onOpen: (id: string) => void }) {
  const world = useStore((s) => s.world!)
  const img = useMemo(() => new Map(world.entries.map((e) => [e.id, e.base.image])), [world.entries]) // портреты
  const [year, setYear] = useState(1010)
  // … вычисления из data по году …
  return (
    <div className="xx">
      <div className="xx-head">…заголовок: кто правит в выбранный год + статус-плашка…</div>
      <div className="xx-slider"><input type="range" … /></div>
      <div className="xx-main">
        <svg viewBox="0 0 360 360" className="xx-pic">…метафора…</svg>
        <div className="xx-card">…карточка выбранного: портрет, имя, годы, заметка…</div>
      </div>
      …списки: история, голоса, залоги…
      <ul className="xx-rules">{data.rules.map((r) => <li key={r}>{bold(r)}</li>)}</ul>
    </div>
  )
}
```

### Обязательные элементы экрана
- **Шапка:** кто у власти в выбранный год + статус (горит/штиль/шторм) — цветная плашка.
- **Переключатель времени:** ползунок лет или вкладки событий (выборы, отводы, переписи).
- **Метафора в SVG:** колесо, гора, море, урна, стена, круг камней — **не таблица**.
- **Клик по людям/гербам** → `onOpen(id)` открывает запись. Портреты — `assetUrl(img.get(id))`.
- **Карточка выбранного** справа (на узком экране — снизу).
- **Списки событий механики** с цветными плашками статуса.
- **Легенда** цветов и **правила** (`rules`, с жирными именами).

## 3. Приёмы SVG, которые уже работают

- **Дуга-сектор** (колесо, полукруг зала) — функция `arc(cx, cy, r0, r1, a0, a1)` в `Lantern.tsx`.
- **Раскладка N предметов по колоннам** с округлением — `shares()` (метод наибольших остатков) в `Fleet.tsx`.
- **Анимация перехода** — CSS `transition: transform 1s` на `<g style={{ transform: translate(...) }}>`
  (кораблики в `Fleet.tsx` плывут между колоннами).
- **Мерцание огня** — `@keyframes` с `opacity` и `transform-box: fill-box` (`.lan-flame`).
- **Штриховка** — `<pattern>` в `<defs>` (отведённая очередь в `Lantern.tsx`).
- **Эмблема герба в круге** — `<g transform={`translate(${x-9} ${y-9}) scale(.18)`}>{EMBLEMS[e].draw(color, bg)}</g>`.
- **Портрет в круге внутри SVG** — `<clipPath>` + `<image href=… preserveAspectRatio="xMidYMid slice">`.
- **Подписи лет без наложения** — показывать подпись, если до соседней точки больше 26 px (`Fleet.tsx`).

### Цвета
Тёмный фон с радиальным градиентом в цвет страны, светлый текст, акцент — цвет органа (золото/медь).
Цвета сторон берутся из `data.sides`. Контраст на тёмном: тексты `#d8d4be` и светлее, подписи `#a8a888`.

## 4. Телефон (обязательно проверить)

- Альбомная **915×412**: шапка карточки государства занимает много — экран должен помещаться
  по ширине и листаться до конца.
- Узкий портрет (<560 px): `grid-template-columns: 1fr` — метафора сверху, карточка снизу.
- Мелкие подписи в SVG ≥ 9 px, кнопки ≥ 28 px высоты.

## 5. Проверка в браузере (рецепт)

Dev-сервер уже есть в панели браузера (вкладка `seed`, `http://localhost:5199`). Рецепт для
`javascript_tool`:

```js
// дождаться загрузки мира (большой world.json грузится 10–40 с)
for (let i = 0; i < 40 && !window.__store; i++) await new Promise((r) => setTimeout(r, 2000))
const s = window.__store.getState()
const st = s.world.states.find((x) => x.base.name === 'ИМЯ СТРАНЫ')
s.openStateCard(st.id)
await new Promise((r) => setTimeout(r, 2000))
;[...document.querySelectorAll('button')].find((b) => b.textContent.trim().startsWith('Власть')).click()
await new Promise((r) => setTimeout(r, 1500))
// прокрутить модальное окно к экрану
const el = document.querySelector('.xx'); let p = el.parentElement
while (p && p.scrollHeight <= p.clientHeight + 2) p = p.parentElement
p.scrollTop += el.getBoundingClientRect().top - 120
```

Потом — `computer screenshot`. Для телефона: `resize_window {width: 915, height: 412}`, перезагрузка,
тот же рецепт, в конце — `resize_window {preset: 'desktop'}`.

После правок `seed-lore`/`world.json` — перезагрузить страницу (`location.reload()`); после правок `.tsx` —
обычно хватает горячей перезагрузки.
