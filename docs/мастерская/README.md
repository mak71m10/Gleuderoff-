# Мастерская Gleuderoff

Учебник для модели, которая ведёт проработку стран **целиком**: придумывает власть и историю, пишет лор,
строит экран власти, города и 3D. Пошаговый технический порядок работы — в
[`docs/как-добавить-страну.md`](../как-добавить-страну.md); здесь — **ремесло**: как сделать хорошо.

## Творческий цикл страны (коротко)

1. **База и вопросы** — что о стране уже есть (`owners`, соседи, grep по лору); 6–8 вопросов автору.
2. **Канон** — ответ автора дословно в `source-lore/<Страна>.md`. Канон главнее любой выдумки.
3. **Одна фраза-странность** — чем страна запомнится (файл 1, раздел 4).
4. **Механика власти** — генератор (файл 2, раздел 3): законность → что считается → порог и цикл →
   сбой с именем → кто держит за горло → забытая статья → трещина 1010 → история механики → картинка.
   Найди 2–3 настоящих образца (файл 6). Проверь тестом готовности.
5. **История** — пять слоёв, цепь «поэтому/но», правители, тайная версия (файл 3).
6. **Дизайн-бриф** — в `docs/handoff.md` по шаблону (файл 2, раздел 5).
7. **Лор-файл** — по брифу, голосом из файла 1; перечитай чеклист абзаца.
8. **Карта, экран, города, 3D, портреты, миграция, конвейер** — технический гайд + файлы 4–5.
9. **Проверка** — браузер, телефон 915×412, 3D днём и ночью, `tsc`, `strip-draft`.
10. **Отчёт автору** — что сделано, что **не проверено**, вопрос про релиз.

## Планка качества

Страна готова, если:
- её **странность** можно сказать одной фразой, и она видна в каждой деревне;
- у власти есть **числа, сбой и трещина 1010 года**;
- у правителей и домов есть **желания и раны**, а у половины людей — **тайны, связанные сетью**;
- экран — **картинка с ползунком**, а не таблица;
- в 3D есть **хотя бы одна особая постройка**, которой нет у других стран;
- лор связан с соседями **минимум тремя нитями** и ничему написанному не противоречит.

Если что-то из этого не получилось — не скрывай: напиши автору, что именно и почему.
