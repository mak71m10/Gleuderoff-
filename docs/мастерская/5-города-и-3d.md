# 5. Города, планы и 3D: как это устроено и как делать новое

Цепочка: **провинция с поселением** → `cities-auto.mjs` (параметры города) → `city-maps.mjs gen`
(генератор Watabou в скрытом окне Electron строит план) → `city-maps.mjs` (рендер `.webp`, контуры
`.plan.json`, карта города в `world.maps`, метки примечательных мест) → `city3d.ts` (3D из плана в
приложении).

---

## 1. Параметры города: `scripts/lore/cities-auto.mjs`

### 1.1. Страна должна быть в цикле
Строка `for (const sn of ['Империя', 'Корона Аргус', …, 'Княжества Гарефорда']) {` — **добавь имя страны**.
Без этого у страны **нет ни одного плана** (так случилось с Гарефордом в первый заход).

### 1.2. Флаг страны и ветки
Рядом с `const cr = sn === 'Крайдонианская Лига'` — свой флаг (`const gf = sn === 'Княжества Гарефорда'`).
Дальше флаг вставляется в длинные цепочки `cond ? … : cond ? … : …` — **перед** веткой `ch ?`
(так добавлены `gf` и `cr`). Места:

| Что | Где искать | Что даёт |
|---|---|---|
| `capital` | `const capital = (gf && world.places.find((x) => x.id === 'lore-gf-capital' && x.base.name === p.name)) \|\| …` | столица = место `lore-<префикс>-capital` с тем же именем, что провинция |
| `size` | `const size = cr ? (…) : gf ? (…) : ch ? …` | размер: столица ~22, город 14–16, порт 11–14, городок 9–11, замок 7, деревня 4–7 |
| `gen` | объект `gen` | `walls`, `citadel`, `plaza`, `temple`, `river`, `coast`, `shantytown`, `greens` (0/1) |
| `dry`/`wet` | `const dry = … : gf ? (…) :` / `pickN(cr ? CR_WET : gf ? GF_WET : …` | названия кварталов: сухие и у воды (свои массивы `XX_DRY`, `XX_WET`) |
| `style` | `...(cr ? { style: 'cray' } : {}), ...(gf ? { style: 'garef' } : {})` | ключ 3D-стиля из `STYLES` |
| `citadelName` | `citadelName: cr ? (…) : gf ? (…) : ch ?` | имя цитадели/замка |
| `landmarks` | `...(gf && capital ? [[имя, вид, правило, текст], …] : [])` | примечательные здания |
| охрана юга | `!hl && !ch && !cr && !gf ? (() => { const r = SOUTH.find…` | **добавь `&& !xx`**, иначе падение `r.hall undefined` на столице |

### 1.3. Примечательные места (`landmarks`)
`[имя, вид, правило, текст]`. **Важно: метка не строит новое здание** — она выбирает уже существующее
здание плана по правилу и подписывает его (в 3D оно становится «особым» по виду).

- **Вид:** `assembly` (зал власти), `castle`, `temple`, `tower`, `landmark`.
- **Правило выбора здания** (`city-maps.mjs`, функция `pick`):
  `center` — ближе к середине · `citadel` — внутри цитадели · `plaza` — у главной площади ·
  `temple` — особое здание или у середины · `water` — у воды · `river` — у реки · `gate` — у начала
  главной дороги · `edge` — на краю · `ring` — на кольце вокруг середины · `in:Квартал` / `castle:Квартал`
  — самое большое здание квартала.
- Особые постройки (башня на площади, корабли, маяк, платформа) — это **код в `city3d.ts`** (раздел 3).

## 2. Генерация планов: `scripts/city-maps.mjs`

```bash
# 1) slug'и городов страны (временный скрипт в scripts/, потом удалить)
cat > scripts/_slugs_tmp.mjs <<'EOF'
import { readFileSync } from 'fs'
import { CITY_MAPS } from './lore/cities.mjs'
import { autoCities } from './lore/cities-auto.mjs'
const world = JSON.parse(readFileSync('resources/default-world/world.json', 'utf8'))
console.log((await autoCities(world, CITY_MAPS)).filter((c) => c.state === 'ИМЯ СТРАНЫ').map((c) => c.slug).join(' '))
EOF
SL=$(node scripts/_slugs_tmp.mjs); rm scripts/_slugs_tmp.mjs
# 2) сгенерировать и привязать ТОЛЬКО свои города (в фоне, 10–30 мин)
node scripts/city-maps.mjs gen $SL
```

**Ловушки:**
- `city-maps.mjs gen` **без slug'ов** генерирует только отсутствующие, но **перерисовывает все** `.webp`
  мира — потом в `git status` десятки чужих изменённых картинок. Их вернуть:
  `git status --short resources/default-world/maps/cities | grep "^ M" | awk '{print $2}' | xargs git checkout --`
- Если меняешь параметры города, у которого план уже есть, — `gen <slug>` (с именем) перегенерирует его.
- `world.json` бывает занят dev-сервером: ошибка `UNKNOWN: unknown error, open` → просто повторить.
- **Не запускать параллельно** скрипты, которые пишут `world.json` (портреты + привязка планов): последний
  перезапишет первого. Порядок: портреты → `city-maps` → `army-routes` → `strip-draft`.
- PNG-файлы в `source-maps/cities/*.png` — промежуточные, **не коммитить**.

Результат: `resources/default-world/maps/cities/<slug>.webp` и `<slug>.plan.json`, у провинции — `cityMapId`.

### Что внутри `.plan.json`
`w, h, districts, buildings, landmarks, scene` — где `scene`:
`style` (ключ STYLES), `squares` (площади), `water`, `walls`, `roads`, `rivers`, `fields`, `greens`,
`citadel`, `planks`, `forest`, `tower`, `droof`, `dist`. 3D строится только из этого файла.

## 3. 3D: `src/renderer/src/city3d.ts`

### 3.1. Стиль = палитра (`STYLES`)
```ts
garef: { plaster: [...5 цветов стен], roof: [...5 цветов крыш], timber: '#2f2014', stone, wall,
         shutter: [...ставни], pitch: 1.05 /* крутизна крыш */, framed: true /* фахверк */, floors: 1,
         grass, grass2, dirt, pave, lit: 0.45 /* доля светящихся окон ночью */, conifer: 0.8 /* доля елей */,
         tower: '#4f8a74' /* шпили, башни */ },
```
Нужна только новая палитра — добавь запись в `STYLES` и таблицу народов в `city3dRaces.ts`
(`garef: { imperials: 86, dwarves: 3, … }` — доли жителей на улицах; ключи народов — как в соседних строках).

### 3.2. Новая геометрия — где вставлять
`buildCity(plan, seedName, opts)` строит всё. Полезное внутри:

| Имя | Что это |
|---|---|
| `S` | `plan.scene`; `S.style` — ключ стиля; флаги вида `const kranz = S.style === 'kranz'` |
| `st` | палитра `STYLES[S.style]` |
| `W, H, center, radius` | размеры плана, середина, радиус застройки |
| `heightAt(x, z)` | высота земли; `< -0.9` — вода |
| `gridAt(x, z)` | клетка сетки: `0` пусто, `1..N` — здание (№+1), особые значения — площади/занятое |
| `fillLine(points, width, id)` | **занять** клетки (чтобы жители не ходили сквозь постройку) |
| `squares` | контуры площадей; `centerOf(r)`, `areaOf(r)` |
| `chunkAt(x, z)` | ведёрки участка: `.solid` (стены), `.roof` (крыши, текстура черепицы), `.glow` (светится ночью) |
| `Bucket` | `box(x, y, z, sx, sy, sz, col, rot)` — коробка, **y — низ**; `cyl(x, y, z, r, h, n, col, r2, cap, rot)` — тело вращения (`r2 = 0` конус, `n = 4` пирамида) |
| `solidMat`, `roofMat`, `glowMat` | материалы для отдельных ведёрок (`new THREE.Mesh(bk.geometry(), mat)`, `scene.add`, `disposable.push(g)`) |
| `rng(hashOf(seedName) + N)` | детерминированный случай — **только так**, иначе город меняется при каждом открытии |
| `mixHex(a, b, k)` | смешать цвета |
| `opts.mobile`, `detail` | на телефоне меньше объектов: ограничивай количества |

Готовые образцы особых построек:
- **Памятник на главной площади** — цикл `squares.forEach((r, si) => …)`: ветка `si === garefSq`
  (Светочная башня Гарефорда на самой большой площади; `garefSq` считается перед циклом).
- **Море:** блок `if (S.style === 'cray')` внутри `if (hasWater)` — сканирование воды у берега сеткой,
  корабли, свайные дома, маяк на молу.
- **Рельеф и платформа:** `kranz` — город на платформе вокруг вершины, блокировка клеток скалы и края.

### 3.3. Правила новой геометрии
1. Всё в ведёрки, а не отдельными мешами (тысячи объектов — тысячи мешей тормозят телефон).
2. Светящееся (окна, фонари, огонь) — в `.glow` или в ведёрко с `glowMat`, цвет `'#ffffff'`.
3. Занимай клетки `fillLine`, иначе жители и прогулка проходят сквозь.
4. Количества ограничивай (`Math.min(24, …)`) и уменьшай на `opts.mobile`.
5. Цвета — из `st` (палитра стиля), чтобы постройка была «своей».

## 4. Проверка в 3D (рецепт)

```js
for (let i = 0; i < 40 && !window.__store; i++) await new Promise((r) => setTimeout(r, 2000))
window.__store.getState().openMap('map-city-<slug>')
await new Promise((r) => setTimeout(r, 2500))
;[...document.querySelectorAll('button')].find((b) => b.textContent.trim() === '3D').click()
await new Promise((r) => setTimeout(r, 9000))
;[...document.querySelectorAll('button')].find((b) => b.textContent.trim() === 'Ночь')?.click()
```
Кнопки над видом: **Карта / 3D / Прогулка**, **День / Вечер / Ночь**, **Подписи** (метки мешают
смотреть — выключи), **Расы**, **Чистый вид**. В 3D: колесо — масштаб к курсору, перетаскивание — поворот.

**Если постройку не видно:**
1. Временный лог: `console.info('XX', значения)` в нужном месте → перезагрузка → `read_console_messages`
   с `pattern: 'XX'` — сработала ли ветка, сколько площадей, какой стиль.
2. Временно увеличь постройку в 5–10 раз (через `window.__X`-переменную) — сразу видно, где она стоит.
3. **Обязательно убери** отладку перед концом работы (`grep -n "console.info\|__X" city3d.ts`).

Временная подмена стиля для проверки на чужом плане: `sed -i 's/"style":"empire"/"style":"xxx"/' <plan>`
— и **обязательно** `git checkout -- <plan>` после.
