# 7. Родословные древа: как их строить и рисовать

Родословное древо открывается на странице династии («Династии» → дом) и в карточке государства. Оно **строится само** по ссылкам у персонажей:
`отец`, `мать`, `супруг`, `супруг 2`, `супруг 3` (поля `links.father`, `links.mother`, `links.spouse`, `links.spouse2`, `links.spouse3`) и по ссылке на династию (`links.dynasty`).
Рисует его `src/renderer/src/components/DynastyTree.tsx`.

## 1. Что умеет древо

- **Крупные карточки** с портретом, именем, годами жизни, должностью; женские портреты — с арочным верхом.
- **Браки**: супруг рисуется рядом через значок ⚭; несколько браков — подряд; у детей от второго брака подпись «от …».
- **Ветви**: дети первого поколения красят свои линии и карточки в свои цвета (в легенде — «ветвь Адельхайд» и т. д.).
- **Поколения** римскими цифрами в углу карточки; **правители** помечены короной ♛ (по слову в должности: Король, Князь, Граф, Герцог, Конунг, Протектор, Светочедержец и т. п.).
- **Чужие дома**: муж или жена из другого дома — с плашкой «Дом …»; потомки дочерей показываются на одно колено пунктирной рамкой.
- **Подсчёт**: сколько человек, поколений, правителей, годы.
- Масштаб: колесо с Ctrl, перетаскивание, «На весь экран».

## 2. Как писать родословную дома (файлы `scripts/lore/families/*.mjs`)

Каждый файл — модуль с `TAG` (метка страны, она же выбирает стиль портретов), `RACE` (необязательно) и `SPECS` — по одному элементу на дом:

```js
{
  dyn: 'tm-house-temer',            // id династии без lore-
  people: [ /* новые люди */ ],
  patch: [ /* связи уже существующих людей */ ]
}
```

Новый человек — кортеж:

```js
[ключ, имя, пол('m'|'f'), родился, умер|null, отец, мать, супруг, должность/суть, текст, образ, дом, тайна]
```

- **ключ** — уникальный по всем файлам, с префиксом дома: `tT-gun` (id записи будет `lore-fm-tT-gun`, портрет — `fm-tT-gun.webp`).
- **отец / мать / супруг** — ключ нового человека (`'tT-gun'`), уже существующий (`'@tm-foltest'` — id без `lore-`), или `null`. Супругов записывай **с обеих сторон**.
- **образ** — `'noble' | 'cleric' | 'soldier' | 'merchant' | 'scholar' | 'folk' | 'child'`: из него и из возраста сам собирается внешность для портрета.
- **дом** — если человек принадлежит не этому дому (жена из другого дома, зять): `id` его династии (`'tm-house-viesau'`). Дети берут дом **отца**, если не указано иное.
- **тайна** — необязательно; у каждого пятого-десятого человека.

`patch` — ссылки существующим: `['@tm-foltest', { father: 'tT-gun', mother: 'tT-els', spouse: '@tm-berta' }]`; ключ `text` заменяет описание (если родство
меняет смысл прежнего текста). Недостающие записи программа выводит предупреждением `families: нет записи …`.

Подключение: модуль импортируется в `scripts/lore/families.mjs` (списки `[TM, GF, CR, CH, MISC]`); вызов уже стоит в `scripts/seed-lore.mjs`.

## 3. Как придумывать, чтобы древо было красивым

1. **Минимум три поколения вниз** от самого известного человека дома и **одно-два вверх** (родители, дед-основатель: беглый легионер, первый рудокоп, меняла).
2. **Ветви.** У правителя — 3–5 детей разного характера: наследник, смелый, священник, дочь в чужом доме, умерший ребёнок. Каждая ветвь — своя будущая линия игры.
3. **Браки — это политика.** Жена из соседнего дома связывает два дома; указывай, что она принесла (союз, долги, обиду).
4. **Смерти.** Часть людей умирает рано (бой, болезнь, «несчастный случай»): тогда древо рассказывает историю, а не просто растёт.
5. **Крючки.** Внук-наследник вместо двух взрослых претендентов; старший законный сын по отцу против сына по матери; зять, у которого больше голосов.
6. **Возраст правдоподобен:** родители старше детей минимум на 16 лет; жена не старше мужа больше чем на 10; вдова не рожает через 10 лет после смерти мужа.
7. **Имена:** по языку культуры дома; имена детей повторяют имена дедов и дядей (так в старых семьях называют: Фольтест → Фольтест Тальау → …).
8. Текст человека — как в `1-как-писать-лор.md` (раздел 3): должность, одна видимая деталь, поступок, слабость.

## 4. Портреты новых людей

Портреты генерирует `node scripts/portraits.mjs` (никого, у кого файл уже есть, не пересоздаёт; ~20 секунд на человека). Образ берётся из `props.look`, который
`families.mjs` собирает из пола, возраста и роли; для важных людей можно задать описание вручную в `CUSTOM` (`scripts/portraits.mjs`).
**Портреты и конвейер не запускать одновременно** — оба пишут `world.json`.

## 5. Чеклист родословной

- [ ] У главных людей дома есть отец, мать, супруг(а) и дети (где по возрасту возможно).
- [ ] Супруги записаны с обеих сторон; `tsc` и `seed-lore` без предупреждений.
- [ ] Минимум 3 поколения; хотя бы одна ветвь заканчивается рано или уходит в чужой дом.
- [ ] Дети правдоподобного возраста; ни одного ребёнка старше родителя.
- [ ] Новые люди получили портреты; древо проверено в приложении (на весь экран).
