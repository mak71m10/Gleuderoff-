## Заметки
- Никогда не запускать `seed-lore` отдельно — только весь конвейер (шаги падают на блокировке `world.json`, повторять; node `--max-old-space-size=8192`). Порядок — в `docs/как-добавить-страну.md`.
- `history` у `st` для регулярно сменяемых правителей — датировать `Y(год)`: «сегодня» = `Y(1010)`.
- `city-maps gen` может упасть по таймауту на одном городе — `RESEED[slug]` в `cities-auto.mjs` и `gen <slug>`.
- Не читать большие файлы целиком (kulagon.mjs, Cart.tsx) — иначе автосжатие контекста зацикливается.
- Коммит: `git add -A -- . ':!video' ':!vk' ':!scripts/vk-*.mjs' ':!.gitignore' ':!source-maps/cities/*.png'`, затем `git reset -q -- .gitignore`.
