## Заметки
- Никогда не запускать `seed-lore` отдельно — только весь конвейер (шаги падают на блокировке `world.json`, повторять; node `--max-old-space-size=8192`).
- `history` у `st` для регулярно сменяемых правителей — датировать `Y(год)`, а не `Y(год + дробь)`: «сегодня» = `Y(1010)`.
- `city-maps gen` может упасть по таймауту на одном городе — `RESEED[slug]` в `cities-auto.mjs` и `gen <slug>`.
- Не читать большие файлы целиком (kulagon.mjs, patch_kg_all.py, Cart.tsx) — иначе автосжатие контекста зацикливается.
