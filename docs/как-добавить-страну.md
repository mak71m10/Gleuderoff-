# Как добавить страну в Gleuderoff

Подробная инструкция для любой модели (Sonnet, Opus, Haiku), которая продолжает проработку стран мира.
Написана 07.11.2026 на примерах Фарвольской лиги (0.33) и Высокогорного Княжества (0.34).

Читать целиком перед первой страной. Дальше — как справочник по шагам.

---

## 0. Кто что делает: Sonnet и Opus

Автор экономит лимиты: основную работу ведёт **Sonnet**, а **Opus** включают только на шаги,
где нужна изобретательность или сложная геометрия. Шаги в этой инструкции помечены:

- 🟢 **[SONNET]** — делается по образцу, Sonnet справится.
- 🔴 **[OPUS]** — нужна новая идея или сложный код. Sonnet этот шаг **не делает**.

### Кто какую часть страны делает

Страна делится на три захода — так автор видит работу обеих моделей, а Opus тратится только на нужное:

1. **Sonnet, до Opus** (заметная работа, а не «прочитал и передал»): изучить базу и задать вопросы
   (разделы 2–3); после ответа автора — сохранить канон, **подключить страну к планам городов** (8.1),
   **подобрать 3D-палитру** (8.2, если хватает палитры), **заготовить стиль портретов** (11, без `CUSTOM`),
   **заготовить миграцию** (9), шаг в README, `docs/handoff.md` с выжимкой базы. Всё это от механики власти
   не зависит. И только потом — переключение на Opus.
2. **Opus**: механика власти (4), **ядро лора, тесно связанное с ней** — дома, правители, совет/участники
   механики с портретными описаниями, данные по годам, организации власти, поля страны (5), экран (7),
   новая 3D-геометрия, если нужна. Проверка экрана в браузере.
3. **Sonnet, после Opus** (самая объёмная часть): описания всех поселений, места и походы (6),
   книги, конвейер (10), планы городов, портреты по `CUSTOM` от Opus (11), проверка (12), релиз по просьбе (13).

В сообщении о переключении Sonnet **перечисляет, что сделал сам**, чтобы автор видел работу модели.

### Протокол переключения моделей (обязателен)

Когда работа дошла до шага 🔴 [OPUS], а сейчас работает не Opus:

1. Доделай все 🟢-шаги, которые можно сделать **до** этого шага (заход 1 выше), и проверь их.
2. Запиши состояние в `docs/handoff.md` (шаблон — в конце этого файла): страна, что сделано,
   какие файлы созданы, что осталось, ответы автора (дословно или ссылкой на `source-lore/<Страна>.md`).
3. Последним сообщением хода напиши автору **отдельной строкой, крупно**:

   > **🔴 Переключи модель на Opus** и напиши: «Продолжай по docs/handoff.md».

   И одной фразой — зачем нужен Opus (например: «придумать систему власти и её экран»).
4. Ничего не начинай из 🔴-шага, даже «черновик на пробу»: Opus всё равно переделает.

Когда работает Opus и 🔴-шаги закончились, а дальше только 🟢-шаги:

> **🟢 Можно переключиться обратно на Sonnet** и написать: «Продолжай по docs/handoff.md».

Перед этим Opus тоже обновляет `docs/handoff.md`.

Если Sonnet сделал 🟢-шаг, а результат вышел плоским или что-то сломалось и за две попытки
не чинится, — тоже протокол переключения: «🔴 Переключи на Opus: нужна проверка/починка X».

Автор может переключать модель прямо в этой же сессии (выбор модели в приложении): разговор
сохраняется, но `docs/handoff.md` всё равно пишем — на случай новой сессии.

## 1. Общие правила проекта (нарушать нельзя)

- Отвечать автору **по-русски**, коротко и понятно, без жаргона.
- **Gleuderoff — весь мир. Лора — только один континент.** Не называть мир «Лорой».
- Всё, что придумано не автором, — пометка **«черновик»** (тег `черновик` у записей, `_черновик_` в описаниях).
- Тайны мастера — только в поле `secret` (видны в режиме мастера), не в обычном тексте.
- Канон автора важнее всего. Не придумывать **правителей, даты и причины войн**, если автор их дал или
  если это ломает его текст. Если автор написал «остальное придумай сам» — придумывай смело, но с пометкой.
- **У каждой страны — своя, уникальная система власти.** Не парламент в другой обёртке.
  Она обязательно видна во вкладке **«Власть и законы»** карточки страны (StateCard), а не только
  на карточке организации. Автор злился, когда было иначе.
- Портреты людей — **северноевропейские лица**, никогда не азиатские (кроме прямо оговорённых народов юга).
- **Коммит и пуш — только когда автор попросит.** В коммит не входят `video/`, `vk/`, `scripts/vk-*.mjs`, `.gitignore`.
- Никогда не читать и не показывать `vk/.env`. Токены и ключи не вводить никуда.
- Ссылки на скачивание давать **только на страницу релиза GitHub**, не прямые ссылки на файлы:
  `https://github.com/mak71m10/Gleuderoff-/releases/tag/vX.Y.Z`.

## 2. Как изучить базу перед страной 🟢 [SONNET]

Прежде чем задавать вопросы, узнай, что о стране уже есть в мире. Всё лежит в
`resources/default-world/world.json` (большой файл — не читать целиком, только через `node -e`).

### 2.1. Сама страна, провинции, соседи

```bash
node -e "
const w=require('./resources/default-world/world.json');
const s=w.states.find(s=>s.base.name==='ИМЯ СТРАНЫ');
console.log(JSON.stringify(s.base,null,1).slice(0,1500));
const ad=new Map(w.adminRegions.map(a=>[a.id,a]));
const ps=w.provinces.filter(p=>p.owners?.at(-1)?.[1]===s.id);
console.log('провинций',ps.length);
const by={};for(const p of ps){const t=p.settlement?.type||'-';by[t]=(by[t]||0)+1}console.log(by);
const land=p=>ad.get(ad.get(p.areaId)?.parentId)?.name;
const g={};for(const p of ps){const k=land(p)+' / '+ad.get(p.areaId)?.name;(g[k]=g[k]||[]).push(p.name+'('+(p.settlement?.type||'-')[0]+',рельеф '+p.terrain+')')}
for(const k in g)console.log(k+': '+g[k].join(' '));
const nb=new Set();for(const p of ps)for(const n of p.neighbors){const q=w.provinces.find(x=>x.id===n);const o=q?.owners?.at(-1)?.[1];if(o&&o!==s.id)nb.add(w.states.find(x=>x.id===o)?.base.name)}console.log('соседи',[...nb]);
console.log('культуры', [...new Set(ps.map(p=>p.culture))]);
"
```

`terrain`: 1 — равнина, 2 — лес, 3 — холмы, 4 — горы, 5 — высокие горы.
Типы поселений: `city`, `town`, `port`, `castle`, `village`, `fishing`, `temple`, `tower`, `ruins`.

### 2.2. История владения

У провинции `owners` — список `[дата, id владельца]`. Дата — номер дня: **год = дата / 500 + 1**
(в году 500 дней). Владельцы `hist-*` — исторические (Империя гор, повстанцы, Пакт и т. п.).
Посмотри, как страна возникла по `scripts/history-provinces.mjs` (поиск по имени страны и по
множествам `MOUNTAIN`, `NORTH`, `CENTRAL`, `DESERT`, `VASSALS`).

### 2.3. Что о стране уже сказано в лоре других стран

```bash
grep -rn "ИМЯ СТРАНЫ" scripts/lore/*.mjs scripts/*-detail.mjs source-lore/ | cut -c1-200
```

Например, у Изгнанников уже был «набег на Высокогорное княжество 1002 г., князья откупаются
серебром» — это стало частью лора княжества. **Не противоречь уже написанному** — вплетай.

### 2.4. Общие опоры мира

- Календарь «Реквием»: год 500 дней, 5 месяцев. Сейчас **1010 г.** Эпохи: Первая (0–150),
  Вторая/Имперская (150–980), Третья (с 980).
- Распад Империи: гражданская война **975–980**, северные восстания **976–977**, Чёрная комната — **980**.
- Империя: Тейбер I основал её в 150 г. Легионы — `scripts/lore/empire.mjs` (`LEGIONS`).
- Религии: `lore-house-light` (Дом Света), `lore-house-dark`, `lore-house-chaos`, `lore-house-freedom`.
  Боги — `scripts/lore/gods.mjs`. Расы — `scripts/lore/races.mjs`.
- Гербы: допустимые раскладки и эмблемы — в `src/renderer/src/components/Heraldry.tsx` (`EMBLEMS`).
  Если нужной эмблемы нет — добавь её туда (как добавлены `cog`, `wheat`, `sun`).

### 2.5. Образцы, на которые равняться

| Что посмотреть | Где |
|---|---|
| Лор страны целиком (дома, люди, орган власти, события, поля страны) | `scripts/lore/highland.mjs`, `scripts/lore/farvol.mjs` |
| Описания поселений, места на карте, походы армий | `scripts/highland-detail.mjs`, `scripts/farvol-detail.mjs` |
| Экран власти | `src/renderer/src/components/Heights.tsx`, `Vault.tsx`, `Brood.tsx`, `Ting.tsx`, `Stavka.tsx` |
| Миграция мира | `src/main/index.ts`, блоки `if ((user.version ?? 1) < 30)` и `< 31` |
| Планы городов и 3D-стили | `scripts/lore/cities-auto.mjs`, `src/renderer/src/city3d.ts` (`STYLES`), `city3dRaces.ts` |

## 3. Как задавать вопросы автору 🟢 [SONNET]

Автор пишет ответ **одним длинным сообщением своими словами**. Поэтому вопросы — одним
сообщением, пронумерованные, 6–8 штук, короткие, с подсказками-вариантами в скобках.

Сначала одной-двумя фразами — что ты уже знаешь о стране из базы (размер, соседи, что о ней
сказано у соседей). Потом вопросы. Шаблон:

1. **Кто там живёт?** (люди, дварфы, эльфы… кто главный, кто на вторых ролях)
2. **Кто правит и как устроена власть?** Подчеркни: нужна своя, особенная система, не парламент.
3. **Откуда страна взялась?** (откололась от Империи в 975–980? была до неё? как именно?)
4. **Чем живут?** Богатство и слабое место.
5. **Вера?**
6. **Враги и союзники среди соседей** (перечисли реальных соседей из базы).
7. **Как выглядит в 3D?** Архитектура, особые города (на скалах, в лесу, на воде…).
8. «Остальное придумаю сам и помечу „черновик“».

В конце: «Можно и другую страну, если хочешь» — и 3–4 следующие по размеру непроработанные страны.

Ответ автора **сохрани дословно** в `source-lore/<Имя страны>.md` (с небольшой правкой опечаток) —
он канон, к нему возвращаются при переделках.

Если ответ автора неполный — не переспрашивай по мелочам, придумай сам с пометкой «черновик».
Переспрашивай только если без ответа нельзя (например, непонятно, кто правит).

## 4. Придумать систему власти 🔴 [OPUS]

Это главный творческий шаг. **Sonnet его не делает** — протокол переключения (раздел 0).

Что нужно придумать:

- **Механика, а не название.** Не «совет», а правило, по которому власть **считается**:
  - Весы Свода (лига): места палат пересчитываются раз в семь лет по щитам и долям; люди — решающие голоса.
  - Право Высоты (княжество): ранг = высота очага; голос весит высоту; князь поднимает и опускает дома.
  - Выводок и Жатва (Креит), Каменный круг (Север), Сабельная ставка (Изгнанники) — смотри их файлы.
- **Напряжение внутри**: кто кого держит за горло (ключи подъёмников, насосы, Дозор у врат).
- **История механики по годам**: 5–15 точек, где что-то менялось, — для переключателя по годам.
- **Тайна мастера**: что на самом деле происходит (в `secret`).
- **Экран**: как показать механику **картинкой**, а не таблицей. Гора с гербами, весы с чашами,
  круг камней… Должен быть интерактив: переключатель по годам, выбор решения/выборов, клик по гербу.

Результат шага: функция данных (`heightsData()`, `vaultData()`) в `scripts/lore/<страна>.mjs`
и описание экрана для шага 7.

## 5. Лор страны: `scripts/lore/<страна>.mjs` 🟢 [SONNET] (по готовой идее власти)

Копируй структуру `scripts/lore/highland.mjs`. В начале файла — комментарий: что канон автора
(пересказ его ответа), что придумано («черновик»). Дальше:

1. Константы: `TAG`, `STATE` (точное имя страны в мире), имена для генерации (`*_NAMES`).
2. Дома/кланы: массив `[ключ, имя, цвета, эмблема, …, текст]`.
3. Правители: `[id, имя, пол, рождён, умер, правил с, по, титул, текст, тайна]` — 3–5 человек.
4. Люди: 8–14 персонажей с должностью, домом, текстом и **тайной** у половины.
5. События: `[год, название, текст, тип]` — 10–16 штук.
6. Функция данных органа власти (из шага 4).
7. `export default function <страна>({ E, Y, world })`:
   - `E(id, 'dynasty' | 'character' | 'organization' | 'artifact' | 'note' | 'event', имя, поля)`.
     id без `lore-` (его добавит seed-lore). Префикс страны: `hl-`, `fv-`, `kr-`…
   - Орган власти — `organization` с `props.type: 'Государственный орган'` и полем данных
     (`heights`, `vault`…). **Без этого он не появится во вкладке «Власть и законы».**
   - Ещё 4–7 организаций: армия, церковь, гильдии, движения, тайное общество.
   - 1–3 артефакта, иногда заметка (бестиарий и т. п.).
   - Поля страны: `fullName, motto, heraldry, ruler, rulerTitle, rulerId, dynastyId, government,
     ideology, religion, religionId, culture, languages, population, capitalId, army, navy,
     treasury, economy, laws, diplomacy, stability, description, secret` — все заполнить.
   - `st.history` — смена правителей по датам (иначе в прошлых годах будет нынешний правитель).
   - `st.factions` — 4–6 фракций с влиянием (сумма ≈ 100).
8. Функция облика поселений `<страна>Race(name, type, terrain)` → ключ 3D-стиля.

Даты: `Y(год)` превращает год в номер дня. Дробная часть года — месяц (977.3 — весна 977).

Подключить в `scripts/seed-lore.mjs`: импорт, вызов `xxxLore({ E, Y, world })`, и если у органа
новое поле — пропустить его в `E()` (строка `...(f.heights ? { heights: f.heights } : {})`).
Поднять `world.version` на 1.

Записи в книгу гербов: `scripts/lore/books.mjs` — глава по образцу «Адлерхорны и дома Венца».

## 6. Карта: `scripts/<страна>-detail.mjs` 🟢 [SONNET]

Копируй `scripts/highland-detail.mjs`:

- **Переименования** (если автор хочет другие названия городов): массив `*_CITIES` с `id`
  провинции, новым и старым именем; область, названная по старому имени, тоже переименуется.
- **Описание каждого поселения** — 2–4 предложения, живые детали, кто правит, чем живут;
  у особых мест — свой текст. В конце строка «земля; кто живёт» и `\n\n_черновик_`.
  Случайность — только через `rnd()` с фиксированным `seed` (результат должен повторяться).
- **Места на карте** (`place(...)`): столица (`lore-<префикс>-capital`, тип `capital`),
  святыни, битвы (тип `battle` с годом), достопримечательности.
- **Походы армий** (`world.armies`, id `lore-army-<префикс>-…`): точки `pt(провинция, год)`.
- Если меняется история владения — правка в `scripts/history-provinces.mjs`
  (как блок «Высокогорное Княжество» внутри северных восстаний).

Добавить шаг в README (раздел «Сборка стартового мира», после последнего `*-detail`).

## 7. Экран власти 🔴 [OPUS]

Новый компонент `src/renderer/src/components/<Имя>.tsx` по идее из шага 4. Образец — `Heights.tsx`.

- Тип данных — в `src/renderer/src/types.ts` рядом с `vault?`/`heights?`.
- Подключить в `StateCard.tsx` (фильтр `organs` + вывод во вкладке power) и в `Codex.tsx`.
- Стили — в `src/renderer/src/styles.css` с префиксом (`.hts-*`, `.vault-*`) и правило
  в телефонном блоке `@media (max-width: 760px), (max-height: 520px) and (orientation: landscape)`.
- Проверить ширину телефона **915×412** (альбомная) — всё влезает, листается до конца.

## 8. Планы городов и 3D

### 8.1. Подключить страну к генератору планов 🟢 [SONNET]

`scripts/lore/cities-auto.mjs` — по образцу `hl`/`fv`:
- имя страны в список стран цикла;
- флаг страны (`const hl = sn === '…'`) и облик (`hlRace(...)`);
- размеры по облику, стены, названия кварталов (`HL_DRY`, `HL_WET`), стиль (`HL_STYLE`);
- примечательные места столицы и особых городов; имя цитадели.

Правила для примечательных мест: `citadel`, `center`, `temple`, `edge`, `big`, `plaza`, `gate`,
`water`, `river`, `ring` (кольцо вокруг середины).

### 8.2. Новый 3D-облик

- Если хватает существующих стилей (`STYLES` в `city3d.ts`: empire, argus, styria, church, south,
  kalt, norse, viking, exile, dwarf, deep, gnome, alpine, kranz…) или нужна только новая **палитра**
  (цвета стен, крыш, шаг крыши) — 🟢 [SONNET]: добавить запись в `STYLES` и таблицу народов
  в `city3dRaces.ts`.
- Если нужна **новая геометрия** (город в пещере, на платформе вокруг вершины, на воде, на деревьях,
  подъёмники, особый рельеф) — 🔴 [OPUS].

## 9. Миграция мира 🟢 [SONNET]

У автора на ПК живой мир в `Documents\Gleuderoff` — он обновляется миграцией, а не заменой.
В `src/main/index.ts` добавить блок `if ((user.version ?? 1) < N)` **перед** строкой
`// v11–v12: перерисована подложка`, копируя блок `< 31`:
состояние страны (`base`, `factions`, `history`), записи `lore-<префикс>-*` и книги,
провинции страны (имя, владельцы, поселение, описание, `cityMapId`), переименованные области,
новые карты городов, места и армии. `N` = новая `world.version` из seed-lore.

## 10. Конвейер сборки мира 🟢 [SONNET]

После правок лора — **весь** конвейер по порядку (шаги 3–5 из README — провинции, сглаживание,
рельеф — **не** запускать: они пересоздают провинции):


## 11. Портреты 🟢 [SONNET]

`scripts/portraits.mjs`:
- стиль страны (`HIGHLAND_STYLE` — образец) и ветка в выборе `prompt`;
- тег страны в списке тегов, по которым ищутся персонажи;
- описания ключевых персонажей в `CUSTOM` (англ., внешность, одежда, предмет в руках, фон).
- Запуск: `DRY=1 node scripts/portraits.mjs` — проверить, что в списке **только** новые персонажи;
  затем `node scripts/portraits.mjs` (в фоне, ~25–100 с на портрет).
- Перерисовать одного: `SEED_OFFSET=7 node scripts/portraits.mjs <id-без-lore>`.
- Посмотреть **каждый** портрет (Read картинки). Типичные беды: гном вышел человеком или садовым
  гномиком, женщина-дварф с бородой, азиатское лицо, корона на ком не надо. Чинить усилением в `CUSTOM`
  (`(tiny old gnome:1.5)`, `(female dwarf, woman, no beard:1.5)`) и новым `SEED_OFFSET`.
- Если портреты идут медленно (~100 с) — видеокарту занимает что-то ещё (3D в браузере, игра).

## 13. Версия, сборка, релиз 🟢 [SONNET]

Только когда страна готова и **автор попросил** коммит/релиз:

1. `package.json` → `version` +0.1 (0.34.0 → 0.35.0).
2. Сборки (TEMP на диск E:, на C: мало места):
   ```bash
   export TEMP="E:/tmp-build" TMP="E:/tmp-build"
   npm run build:web && npm run android && npm run dist
   ```
   Получатся `release/Gleuderoff-X.Y.Z.apk` и `release/Gleuderoff-Setup-X.Y.Z.exe`.
3. Коммит (без `video/`, `vk/`, `scripts/vk-*.mjs`, `.gitignore`), пуш в `main`.

   (токен берётся из `git credential fill` и **никогда не печатается**; повторный запуск догружает недостающее).
5. Автору — ссылка на **страницу** релиза.

Обновить память проекта (`gleuderoff-project.md`): одна строка — что за страна, какая механика.
