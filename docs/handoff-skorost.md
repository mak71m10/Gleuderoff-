# Скорость и телефон — заметки сессии

Ветка `claude/skorost-04194f`. `docs/handoff.md` не тронут.

## Замер (Сигрестад, `buildCity`, headless Chrome + swiftshader, 915×412 «телефон»)
Стенд: CDP-скрипт вне репозитория; метки по стадиям внутри `buildCity`, потом убраны.

| Стадия | До, мс | После, мс |
|---|---|---|
| Маски + сетка высот | 337 | 76 (маски 2, сетка высот 73) |
| Улицы (`buildStreets` + `roadAt`) | 437 | 173 |
| Сетка занятости | — | 83 |
| Холст земли / материалы | 265 | 266 |
| Вода (цикл сетки + меш) | 140 + 114 | 40 + 75 |
| **`buildCity` всего** | **~1430** | **~800** |
| Первый кадр | 1031 | 450 |

ПК-вид (1280×720, до правок): `buildCity` ≈ 1011 мс, первый кадр ≈ 909 мс. Правки касаются общего кода улиц, вид не менялся.

Важно: в swiftshader реальные «80 с» на слабых телефонах не воспроизводятся; замер показывает относительное сокращение работы. Разброс между прогонами заметный (часть выигрыша — шум, первый прогон шёл с холодным кешем vite).

## Что сделано
- `city3dStreets.ts`: убраны аллокации в горячих циклах — `off.some(...)` с замыканием заменён на индексный цикл; `for…of` с деструктуризацией по `NB` заменён на плоские массивы `NBX/NBY/NBL` и индексный цикл; `dist[q]` читается один раз на ячейку.
- Вид домов, палитры, жители — не менялись.

## Что осталось (идеи, не сделано)
- Холст земли на телефоне (265 мс): меньше эллипсов/крапа и `texMax` — это меняет вид, нужно решение автора.
- Прогрев шейдеров (`renderer.compile`) до первого кадра; первый кадр ≈ 450 мс.
- Порционная сборка с уступкой потоку между стадиями (UI не замирает).
- Телефон: LOD/pixelRatio/тени уже различаются по `mobile` (pixelRatio ≤ 1.5, без antialias, тень отключена при N>500, карта теней 1024); дополнительных урезаний не вводил, чтобы не ухудшить вид.

## Проверки
- `npx tsc --noEmit` — без ошибок.
- Сборка APK: `npm run build:web && npm run android` (результат — в отчёте сессии).
